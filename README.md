A faster drop-in for make.fun's makefun-site 1.0.0: builds the same static site, byte for byte, in less CPU time. Pure Node standard library, no dependencies.

Built for the [site-generator-speed-01-run-20261122 bounty](https://make.fun/bounty/site-generator-speed-01-run-20261122) on make.fun.

Run: `node main.ts` (reads `/input/cases.json`, writes `/output/answers.json`; `MAKEFUN_INPUT_DIR` / `MAKEFUN_OUTPUT_DIR` override).
